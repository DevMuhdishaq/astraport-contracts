# AstraPort Smart Contracts

AstraPort Smart Contracts are built on **Stellar's Soroban framework**.  
They enable portfolio rebalancing, staking, and event-driven actions.

---

## 📂 Repo Structure
- /docs        → Contract documentation
- /examples    → Sample contracts and unit tests
- /src         → Rust-based Soroban contracts
- /tests       → Smart contract test cases

---

## 🔑 Modules
- **Rebalancing**: Adjusts portfolio allocations
- **Events**: Triggers AI analysis on portfolio changes
- **Staking**: Basic staking and alert functionality

---

## 🚀 Tech Stack
- Rust
- Soroban SDK
